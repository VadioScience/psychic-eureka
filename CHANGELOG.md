## [1.0.0] - 2026-10-03

### Added
- ✨ Базовая пушка (BlockLiftGunItem) поднимает блоки в воздух
- ✨ Улучшенная версия пушки (BlockLiftGunItemAdvanced) со звуками и отдачей
- 📖 Полная документация на русском (80+ KB)
- 🔧 Система сборки Gradle с NeoForge 21.1.47
- 🎮 Регистрация предмета через DeferredRegister
- 🌍 Поддержка русского и английского языков
- 🎨 JSON модели для предметов
- ✅ GitHub Actions для CI/CD
- 📝 Templates для Issues и Pull Requests
- 📚 Contributing гайд

### Features
- Поднятие блоков в радиусе 2-3 блока
- Визуальные эффекты (частицы огня и дыма)
- Звуковые эффекты (в Advanced версии)
- Система перезарядки (15 тиков по умолчанию)
- Отдача для игрока (в Advanced версии)
- Исключение обсидиана и коренной породы

### Documentation
- START_HERE.md - быстрый обзор и старт
- QUICK_START.md - запуск за 5 минут
- INSTALLATION.md - полная инструкция установки
- DEVELOPMENT.md - гайд для разработчиков
- API_REFERENCE.md - полный справочник API
- PROJECT_STRUCTURE.md - описание структуры проекта
- EXAMPLES.md - примеры расширения функциональности
- INDEX.md - индекс всей документации
- CONTRIBUTING.md - гайд для контрибьюторов

### Build System
- Gradle 8.2.1 конфигурация
- Java 21+ поддержка
- Автоматическая генерация исходников
- GitHub Actions workflow для сборки и публикации

## Версионирование

Этот проект использует [Semantic Versioning](https://semver.org/):

- **MAJOR** - несовместимые изменения API
- **MINOR** - новая функциональность (совместима)
- **PATCH** - исправления ошибок (совместима)

Примеры версий:
- `1.0.0` - первый major release
- `1.1.0` - добавлена новая функция
- `1.1.1` - исправлена ошибка
