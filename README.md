# Block Lift Gun Mod

Простой мод для Minecraft 1.21.1 (NeoForge), добавляющий пушку, которая поднимает блоки в воздух.

## Возможности

✨ **Основной функционал:**
- Пушка поднимающая блоки (`/give @s blockliftgun:block_lift_gun`)
- При выстреле поднимает блоки в радиусе 2 блоков вверх
- Блоки превращаются в предметы и летят вверх
- Визуальный эффект частиц (огонь)
- Перезарядка 15 тиков между выстрелами

## Установка

### Требования
- Java 21+
- Gradle (опционально, можно использовать встроенный)

### Шаги установки

1. **Клонируйте/скопируйте проект:**
```bash
cd BlockLiftGun
```

2. **Установите dev окружение:**
```bash
./gradlew genSources
```

3. **Откройте в IDE (рекомендуется IntelliJ IDEA):**
```bash
./gradlew idea
```

4. **Скомпилируйте мод:**
```bash
./gradlew build
```

5. **JAR файл будет находиться в:**
```
build/libs/blockliftgun-1.0.0.jar
```

6. **Скопируйте JAR в папку `mods` вашего Minecraft профиля с NeoForge**

## Использование

1. Запустите Minecraft с NeoForge 1.21.1
2. Создайте новый мир
3. Дайте себе предмет командой:
```
/give @s blockliftgun:block_lift_gun
```

4. Прицельтесь на блок и **ПКМ** (right-click) чтобы выстрелить
5. Блоки вокруг поражаемого блока поднимутся в воздух!

## Техническое описание

### Структура проекта
```
BlockLiftGun/
├── src/main/java/com/blockliftgun/
│   ├── BlockLiftGun.java          # Главный класс мода
│   └── item/
│       ├── ModItems.java          # Регистрация предметов
│       └── BlockLiftGunItem.java   # Логика пушки
├── src/main/resources/
│   ├── META-INF/mods.toml         # Конфиг мода
│   └── assets/blockliftgun/
│       ├── lang/                  # Переводы
│       └── models/item/           # 3D модели
├── build.gradle                   # Конфигурация Gradle
└── settings.gradle
```

### Параметры пушки (BlockLiftGunItem.java)

Вы можете изменить:
- `LIFT_FORCE = 1.2f` - сила подъема (больше = выше летят)
- `LIFT_RANGE = 20` - радиус действия в блоках
- `COOLDOWN = 15` - перезарядка в тиках (1 сек = 20 тиков)
